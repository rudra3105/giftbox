# GiftBox 3D Customization Prototype

## Run locally
1. Unzip the folder if downloaded as ZIP.
2. Open `index.html` in Chrome, Safari, or Edge.
3. For a quick client demo, scroll through the homepage, product catalogue, 3D-style box preview, compartment selector, weight selector, and price summary.

## Important
This is a front-end concept demo. The box illustration is a CSS-built interactive mockup, not a photorealistic Three.js model. Product list, prices, weights, and capacity are sample values. The order button does not submit a real order or take payment. Confirm all product data with the client before production.

## Suggested next step
Host the `index.html` file on Netlify, Vercel, or any static web host for a shareable preview link. No backend is required for this demo.
